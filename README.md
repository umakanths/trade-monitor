## Quick Start - Deploy to Vercel (FREE)

### Step 1: Create GitHub Account
1. Go to https://github.com/signup
2. Sign up and verify email

### Step 2: Create Repository
1. Go to https://github.com/new
2. **Name**: `trading-dashboard`
3. **Public** (required for free Vercel)
4. Click "Create Repository"

### Step 3: Upload Files to GitHub

In your GitHub repo, click "Add file" → "Upload files"

**Upload all these files:**
- `package.json`
- `public/index.html`
- `src/App.jsx`
- `src/index.js`
- `.gitignore`

Or you can create them one by one in GitHub's web editor.

### Step 4: Deploy on Vercel

1. Go to https://vercel.com/signup
2. Click "Continue with GitHub"
3. Authorize and select your `trading-dashboard` repo
4. Click "Import"
5. Click "Deploy"

**Done!** You'll get a live URL like `https://trading-dashboard-abc123.vercel.app`

## How to Use

1. Click "Refresh Prices" to load current stock prices
2. Click "+ Trade" on any recommendation to log a trade
3. Enter entry price, shares, and notes from eToro
4. Click "Close" to exit a trade and calculate P&L
5. Track your portfolio performance in real-time
